01 Workflow system

Kanban Flow

Kanban management system

A Kanban-based task management system with front-end and back-end components. The interface is organised around a visual board, making it easier to see work as it moves through different stages.

The problem

Task lists can make it difficult to see what is in progress, what is blocked, and what is complete. Kanban Flow explores a visual, column-based way to organise work and follow its flow.

What it does

  • Organises tasks across workflow stages on a visual board
  • Provides a front-end interface for working with tasks
  • Connects to back-end components that support the application

Project scope

  • Front-end
  • Back-end
  • Task workflow

02 Group project

ProjectPulse

Project & team management platform

A team project designed around project and team management, with distinct Admin, Faculty, and Student roles. The system models users, projects, teams, and contribution logs, supported by a REST API and role-based authentication.

The problem

Academic project work is often spread across documents, messages, and spreadsheets. ProjectPulse explores a central place to manage teams, track projects, and record contributions.

What it does

  • Supports Admin, Faculty, and Student roles
  • Organises users, projects, teams, and contribution logs
  • Uses REST APIs, JWT authentication, and a MySQL-backed data layer

Technology

  • React
  • Spring Boot
  • REST APIs
  • MySQL
  • JPA / Hibernate
  • JWT
  • Docker

03 Web application

Blood Donation Management System

Donor, request, and availability management

A web application concept for managing blood donors, requests, and availability. The project brings donor records, blood requests, and administrative oversight into one workflow.

The problem

Coordinating blood availability and requests can be fragmented and time-sensitive. This project explores a more organised way to track donors, requests, and the status of each request.

What it does

  • Manages donor information and blood availability
  • Supports blood requests and request tracking
  • Includes authentication, admin functionality, and notifications

Focus areas

  • Donor management
  • Blood requests
  • Availability
  • Authentication
  • Admin
  • Notifications
